# Исправление проблем с чартами на дашборде 7

## 🔍 Диагностика проблемы

Чарты на дашборде могут не работать по нескольким причинам. Ниже описаны основные проблемы и способы их решения.

## ⚠️ Наиболее частые причины

### 1. Асинхронные запросы выключены (КРИТИЧНО!)

**Симптомы:**
- Чарты таймаутятся через 60 секунд
- Ошибка "Timeout error: We're having trouble loading this visualization"
- Чарты не загружаются или загружаются очень долго

**Решение:**

1. Откройте Superset: https://superset-railway-production-38aa.up.railway.app
2. Перейдите в **Data** → **Databases**
3. Найдите базу данных **"Ubidex Events DB"**
4. **Кликните на название** базы данных для редактирования
5. Прокрутите вниз до раздела **"Advanced"** или **"Query Execution Options"**
6. **Включите чекбокс "Asynchronous query execution"** ✅
7. Установите **"Query timeout"** = `600` (или больше)
8. Нажмите **"Save"**

**⚠️ ВАЖНО:** После изменения настроек **перезапустите Superset**:
- Railway Dashboard → ваш проект → сервис Superset
- ⋮ (три точки) → **Restart**

---

### 2. Фильтры по дате установлены на период без данных

**Симптомы:**
- Чарты показывают "No results"
- Чарты пустые, хотя данные должны быть

**Решение:**

1. Откройте каждый чарт отдельно:
   - Дашборд → Edit Dashboard
   - Кликните на чарт → **Edit chart**
2. Проверьте фильтры:
   - Найдите секцию **Filters**
   - Найдите фильтр `event_date` или другой фильтр по дате
   - **Измените диапазон дат** на период, где есть данные:
     - Например: `2025-12-01` до `2026-01-31`
     - Или: `2025-11-01` до `2026-01-31`
3. Нажмите **Update chart**

**Или временно уберите фильтр:**
1. Нажмите на фильтр `event_date`
2. Нажмите **Remove** или **X**
3. Нажмите **Update chart**
4. Если данные появятся - проблема в фильтре

---

### 3. Проблемы с SQL запросом в Dataset

**Симптомы:**
- Ошибки SQL при выполнении запроса
- Чарты показывают ошибки синтаксиса

**Решение:**

1. Проверьте Dataset:
   - **Data** → **Datasets**
   - Найдите Dataset, используемый чартом
   - **Edit** → **SQL Editor**
2. Проверьте SQL запрос:
   - Убедитесь, что запрос выполняется в SQL Lab
   - Проверьте синтаксис
   - Убедитесь, что все таблицы и колонки существуют
3. Если нужно, обновите SQL:
   - Используйте актуальную версию из `output/superset_datasets_sql/`
   - Сохраните изменения

---

### 4. Колонка `event_date` не настроена как Temporal

**Симптомы:**
- Фильтры по дате не работают
- Time Range фильтры не применяются

**Решение:**

1. **Data** → **Datasets**
2. Найдите Dataset, используемый чартом
3. **Edit** → **Columns**
4. Найдите колонку `event_date` (или другую дату)
5. Установите **Is temporal** = `True` ✅
6. **Save**

---

### 5. Таймаут веб-сервера

**Симптомы:**
- Чарты таймаутятся даже с асинхронными запросами
- Ошибка через 60 секунд

**Решение:**

Проверьте конфигурацию Superset (`superset_config.py`):

```python
# Должно быть установлено:
SUPERSET_WEBSERVER_TIMEOUT = 600  # 10 минут
SQLLAB_TIMEOUT = 600
SQLLAB_ASYNC_TIME_LIMIT_SEC = 600
```

**⚠️ ВАЖНО:** После изменения `superset_config.py` **обязательно перезапустите Superset** на Railway.

## 🔧 Пошаговая диагностика

### Шаг 1: Проверьте настройки базы данных

1. Superset → **Data** → **Databases** → **"Ubidex Events DB"**
2. Проверьте:
   - ✅ **Asynchronous query execution** включено
   - ✅ **Query timeout** >= 600 секунд

### Шаг 2: Проверьте каждый чарт отдельно

Для каждого чарта на дашборде:

1. Откройте чарт отдельно:
   - URL: `https://superset-railway-production-38aa.up.railway.app/superset/explore/?slice_id={CHART_ID}`
   - Или через дашборд: Edit Dashboard → клик на чарт → Edit chart
2. Проверьте:
   - Загружается ли чарт?
   - Есть ли ошибки?
   - Показывает ли данные?

### Шаг 3: Проверьте Dataset

1. Узнайте Dataset ID из чарта (Edit chart → Dataset)
2. **Data** → **Datasets** → найдите Dataset
3. Проверьте:
   - SQL запрос выполняется в SQL Lab?
   - Колонка `event_date` помечена как Temporal?
   - Есть ли фильтры, которые могут блокировать данные?

### Шаг 4: Проверьте фильтры

1. На дашборде: **Edit Dashboard**
2. Проверьте фильтры:
   - Какие фильтры установлены?
   - Применяются ли они к чартам (Scoping)?
   - Правильные ли значения в фильтрах?

## 🚀 Быстрое исправление

Если чарты не работают, попробуйте в таком порядке:

1. **Включите асинхронные запросы** (см. раздел 1 выше)
2. **Перезапустите Superset** на Railway
3. **Проверьте фильтры по дате** - убедитесь, что период содержит данные
4. **Откройте каждый чарт отдельно** и проверьте ошибки
5. **Проверьте SQL запрос** в Dataset через SQL Lab

## ❓ Если проблема сохраняется

1. **Проверьте логи Superset** на Railway:
   - Railway Dashboard → ваш проект → сервис Superset
   - Logs → ищите ошибки при загрузке чартов

2. **Проверьте логи базы данных**:
   - Убедитесь, что запросы доходят до БД
   - Проверьте, нет ли блокировок или медленных запросов

3. **Упростите SQL запрос**:
   - Добавьте фильтры по дате в сам SQL
   - Используйте материализованные представления
   - Ограничьте количество данных

4. **Создайте новый чарт**:
   - Иногда проще пересоздать чарт, чем исправлять старый
   - SQL Lab → выполните запрос → Explore → создайте новый чарт
