# Исправление проблемы "GitHub Repo not found" в Railway

## Проблема

В Railway показывается ошибка "GitHub Repo not found" для проекта UA-IP-parcer, и деплой не обновляется автоматически.

## Решение

### Вариант 1: Переподключить репозиторий (Рекомендуется)

1. **Откройте Railway Dashboard:**
   - Перейдите в проект "UA-IP-parcer"
   - Откройте вкладку "Settings"

2. **Отключите текущее подключение:**
   - Найдите секцию "Source Repo"
   - Нажмите кнопку **"Disconnect"**

3. **Подключите заново:**
   - Нажмите **"Connect Repo"** или **"New"** → **"GitHub Repo"**
   - Выберите репозиторий `Nalivator3000/UA-IP-parcer`
   - Railway автоматически подключит репозиторий

4. **Проверьте настройки:**
   - Убедитесь, что выбрана правильная ветка (обычно `main`)
   - Проверьте, что "Auto Deploy" включен

### Вариант 2: Проверить доступ к репозиторию

1. **Убедитесь, что репозиторий существует:**
   - Откройте https://github.com/Nalivator3000/UA-IP-parcer
   - Проверьте, что репозиторий доступен и не приватный (или у Railway есть доступ)

2. **Проверьте права доступа Railway:**
   - GitHub → Settings → Applications → Authorized OAuth Apps
   - Найдите "Railway" и убедитесь, что он авторизован
   - Если нет, авторизуйте заново

### Вариант 3: Обновить через Railway CLI

```bash
# Установите Railway CLI (если еще не установлен)
npm install -g @railway/cli

# Войдите в Railway
railway login

# Подключитесь к проекту
railway link

# Проверьте подключение
railway status
```

### Вариант 4: Ручной деплой (временное решение)

Если автоматический деплой не работает:

1. **В Railway Dashboard:**
   - Откройте проект "UA-IP-parcer"
   - Перейдите в "Deployments"
   - Нажмите "Redeploy" или "Deploy"

2. **Или через Railway CLI:**
   ```bash
   railway up
   ```

## Проверка после исправления

1. **Сделайте небольшое изменение в репозитории:**
   ```bash
   cd /path/to/UA-IP-parcer
   echo "# Test" >> README.md
   git add README.md
   git commit -m "Test deploy"
   git push
   ```

2. **Проверьте Railway:**
   - Должен появиться новый деплой автоматически
   - В логах должно быть видно процесс деплоя

## Частые причины проблемы

1. **Репозиторий переименован или удален**
2. **Изменены права доступа к репозиторию**
3. **Railway потерял авторизацию в GitHub**
4. **Реопозиторий стал приватным, а Railway не имеет доступа**

## Если ничего не помогает

1. **Создайте новый проект в Railway:**
   - "New" → "GitHub Repo"
   - Выберите `Nalivator3000/UA-IP-parcer`
   - Настройте переменные окружения заново

2. **Или используйте ручной деплой:**
   - Подключите через Git или Railway CLI
   - Деплойте вручную при необходимости
